## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public repository**, for example `ojuss-portfolio`.
2. Upload all four files to the repository's main branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will provide a published URL similar to:
   `https://YOUR-USERNAME.github.io/ojuss-portfolio/`
7. Replace the placeholder email in `index.html` with your actual email before publishing.
